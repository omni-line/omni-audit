# Support

## Community support

- **Bugs and feature requests:** [GitHub Issues](https://github.com/omni-line/omni-audit/issues)
- **Questions / ideas:** [GitHub Discussions](https://github.com/omni-line/omni-audit/discussions) (when enabled)

Before opening an issue, search existing issues and check the [README](README.md)
for usage, exit codes, and CI flags (`--no-marketing`, `-q`).

## Commercial / product support

Omni Audit is an open-source CLI backed by [Omni Line](https://omniline.app).
For private registry product questions, hosting, or enterprise support, visit
https://omniline.app or contact the Omni Line team through the site.

## Security

See [SECURITY.md](SECURITY.md). Do not report vulnerabilities in public issues.
